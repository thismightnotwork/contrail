Ranking rules and limitations

Highest matching category sets the score; additional categories add at most nine tie-break points. Possible safety/emergency 100; medical 80; diversion/return 70; technical 50; crew/disruption 30; possibly funny/human 20; conversational text 12; readable-text fallback 5. Readability is not an ACARS decoder. The matched phrases are shown on each card. Sorting and filters do not change server retention. Aircraft-history search includes routine messages; keyword-only filters apply to loaded results.

Connection and storage diagnostics


Data: Airframes.io and community feeders. Aircraft details are shown only when supplied, with no invented types, units, routes or positions. No login, API key, upstream REST polling or UDP forwarding. Pause freezes display updates, not server collection.
Saved messages survive refreshes. Persistence across deployments requires the database on your Railway volume. History is limited by age, count and payload size; Top 500 ranks that retained history. Previous-app messages are not automatically imported.
